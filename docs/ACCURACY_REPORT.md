# Accuracy report

Generated by `zig build accuracy-report`; `zig build test` fails when this file is stale. Do not edit by hand. The policy behind it is in `docs/ACCURACY.md`.

Every case is a text from the Universal Declaration of Human Rights (UDHR in XML, revision `588b3f4b2d0467aff54842a4b926551b69d5a66a`), cut to a length in characters and written in one charset with iconv. An answer is **right** when decoding the case's bytes with the named charset gives back exactly the text they encode, so for French text without `€`, ISO-8859-1, ISO-8859-15 and WINDOWS-1252 are all right. "Exact label" counts only the charset the case was written in. uchardet is the C++ original at uchardetz revision `abacfc1fc86ef7618547d7dce7cc7501e756fa31`; chardetz is the default build with every accuracy fix on.

The corpus has 4737 cases: every language and charset pair uchardet claims to detect, and every UDHR text as UTF-8, each at 8, 16, 32, 64, 128, 256 and 1024 characters and in full. 20 needed typographic punctuation replaced by ASCII to fit their charset, and 12 also had a few unrepresentable characters dropped (`tests/accuracy/matrix.txt` has the rules). HZ-GB-2312 is not covered because glibc iconv cannot write it.
