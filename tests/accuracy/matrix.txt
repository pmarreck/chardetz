# Each case is a UDHR text (pinned flake input udhr-src) cut to a length in
# codepoints and transcoded with iconv. The ground truth is not a single label:
# an answer is correct when decoding the case's bytes with the answered charset
# gives back exactly the text the bytes encode. So ISO-8859-1 and ISO-8859-15
# are both right for French text without the characters they disagree on.
#
# Lines:
#   lengths   N...          prefix lengths in codepoints; "full" is the whole text
#   candidate NAME...       charsets an answer may name (every name chardetz
#                           reports except PRINTABLE-BINARY, and HZ-GB-2312,
#                           which glibc iconv cannot decode)
#   text KEY LANG ENC...    udhr_KEY.xml, ISO 639-1 language, target encodings
#   compose KEY CHARSET     encode the text after a round trip through CHARSET
#                           (composes combining accents; UTF-8 cases keep
#                           the text as published)
#   utf8-all                additionally, every UDHR text as UTF-8
#
# The text lines are the language/encoding pairs uchardet claims at the pinned
# revision: its single-byte language models (SbcsGroupProber), its multibyte
# and escape-sequence probers, and its byte-order-mark and UTF-16 handling.
